# Файлы для итогового задания

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.

Здравствуйте
Пакет pkg/api : добавления задач, редактирования задачи, удаления задачи, выполнения задачи, получения списка ближайших задач, 
вычисления следующей даты повторения 

Пакет pkg/server : основной запуск сервера

Пакет pkg/db : создание и открытие базы данных

Реализована задача со звёздочкой: возможно указывать недели и месяцы для повторения задач
